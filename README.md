# Racoon-Finder

Windows 11과 macOS 15에서 쓰는 듀얼 패널 파일 관리자입니다. 아직 개발 중입니다.

## 데모 실행

개발 중인 데모를 내 PC에서 직접 써 볼 수 있습니다. 지금 데모는 **0.4.0**(데모 4판)입니다. `main`과 `feat/…` 브랜치에
커밋이 올라올 때마다 GitHub Actions의 **Demo build**가 OS별 실행 파일을 만듭니다. Windows는 설치 프로그램이나 압축만 풀면
되는 zip으로, macOS는 디스크 이미지(dmg)나 zip으로, Linux는 tar.gz로 받습니다. 서명·공증을 하지 않은 데모라서 처음 열 때
OS가 경고합니다.

> **주의:** 데모는 진짜 파일을 옮기고 지웁니다. 처음에는 연습용 폴더에서 써 보세요. 예를 들어 바탕 화면에
> `연습` 폴더를 만들고 아무 파일이나 복사해 넣은 뒤, 그 안에서만 옮기고 지워 봅니다. 3판의 다른 앱과 주고받는
> 끌어 놓기는 실제 PC에서 처음 써 보는 기능이라, 탐색기·Finder와 끌어 주고받을 때도 연습용 파일로 먼저 해 봅니다.
> 4판의 링크 만들기와 설치·제거("완전 삭제")도 처음에는 연습용 폴더와 연습용 PC에서 해 봅니다.

### 내려받기

버전 태그가 붙은 데모는 저장소의 **Releases**에서도 내려받을 수 있습니다. 0.4.0
([v0.4.0](https://github.com/doguri25/Racoon-Finder/releases/tag/v0.4.0))에는 아래 표의 일곱 파일이 있습니다(압축 파일
넷, Windows 설치 프로그램 둘, macOS 디스크 이미지 하나). 0.3.0 이전 판에는 압축 파일 네 개뿐입니다. 개발 중인 최신 빌드는
아래처럼 Actions에서 받습니다.

1. GitHub에 로그인합니다. Actions 산출물은 로그인해야 내려받을 수 있습니다.
2. 이 저장소의 **Actions** 탭 → 왼쪽 목록의 **Demo build** → 초록 체크 표시가 붙은 최근 실행을 엽니다. 0.4.0 데모는
   `feat/m1-core` 브랜치(합친 뒤에는 `main`)의 실행입니다. 실행 제목 옆의 브랜치 이름으로 고릅니다.
3. 아래쪽 **Artifacts**에서 내 PC에 맞는 파일을 내려받습니다. 산출물은 30일 동안 남아 있습니다. 세 OS의 파일은 같은
   실행에서 함께 만들어집니다: Windows는 zip과 설치 프로그램(`.exe`), macOS는 ad-hoc 서명한 `.app`을 담은 dmg와 zip,
   Linux는 tar.gz입니다.

| PC | 파일 |
| --- | --- |
| Windows 11 (대부분의 PC) | `RacoonFinder-demo-windows-x64.zip` |
| Windows 11 ARM (Snapdragon 등) | `RacoonFinder-demo-windows-arm64.zip` |
| Windows 11 설치 프로그램 (x64 / ARM) | `RacoonFinder-setup-<버전>-windows-x64.exe` / `-arm64.exe` (아래 "설치하기") |
| Apple 실리콘 Mac (M1 이후) 디스크 이미지 | `RacoonFinder-demo-<버전>-macos-arm64.dmg` (아래 "macOS 15") |
| Apple 실리콘 Mac (M1 이후) 압축 파일 | `RacoonFinder-demo-macos-arm64.zip` |
| Linux x64 (개발용) | `RacoonFinder-demo-linux-x64.tar.gz` |

Windows에서 어느 쪽인지 모르겠으면 설정 → 시스템 → 정보의 "시스템 종류"를 봅니다("x64 기반 프로세서" 또는
"ARM 기반 프로세서"). Intel Mac용 데모는 아직 없습니다. 압축 파일 안의 `데모-안내.txt`에 같은 안내가 짧게 들어
있습니다.

### 설치하기 (Windows)

설치 프로그램(`RacoonFinder-setup-<버전>-windows-x64.exe`, ARM PC는 `-arm64.exe`)은 **내 계정에만** 설치합니다.
관리자 권한이 필요 없고, 앱은 `%LOCALAPPDATA%\Programs\RacoonFinder`에 들어가며, 시작 메뉴에 **Racoon Finder**
바로 가기가 생깁니다(바탕 화면 바로 가기는 설치 중에 고르면 만듭니다). 알림도 "Racoon Finder"라는 이름과 아이콘으로 뜹니다.

1. 저장소의 **Releases**(0.4.0부터)나 위 "내려받기"의 Actions 산출물에서 `RacoonFinder-setup-…exe`를 내려받습니다
   (Windows 11 ARM이면 `-arm64.exe`). 0.3.0에는 설치 프로그램이 없습니다.
2. 실행합니다. 서명하지 않아서 "Windows의 PC 보호" 창이 뜨면 **추가 정보** → **실행**을 누릅니다.
3. 안내에 따라 설치합니다. 새 버전은 같은 방법으로 위에 덮어 설치하면 됩니다(실행 중인 앱은 설치 프로그램이 닫습니다).

**지우기:** 설정 → 앱 → 설치된 앱에서 Racoon Finder를 지웁니다(앱 안의 보기 ▸ 설정 맨 아래 "제거 프로그램 열기"도
같은 제거 프로그램을 띄웁니다). 먼저 "삭제하기 전에 설정을 백업할까요?"라고 묻습니다.
**예**를 고르면 설정 파일이 문서 폴더의 `RacoonFinder-settings-backup.toml`로 복사됩니다. 그다음 앱이 바꿔 둔 것을
되돌리고, `%APPDATA%\RacoonFinder`(설정·작업 기록), `%LOCALAPPDATA%\RacoonFinder`(캐시·썸네일·로그), 임시 파일,
프로그램 파일, 시작 메뉴·바탕 화면 바로 가기를 지웁니다. 그 밖의 것은 건드리지 않습니다. 정리가 일부 실패하면 종료 코드를
알리는 창이 뜨지만 삭제는 계속됩니다.

**압축만 풀면 되는 zip(아래 "Windows 11")과의 차이:** 설치형은 설정과 작업 기록을 `%APPDATA%\RacoonFinder`에,
캐시와 로그를 `%LOCALAPPDATA%\RacoonFinder`에 두고, zip은 `racoon-finder.exe` 옆의 `data` 폴더에만 둡니다. 두 방식은
서로의 데이터를 쓰지 않고, 설치 프로그램의 삭제는 zip으로 쓰던 폴더를 건드리지 않습니다.

### Windows 11

1. 내려받은 zip을 오른쪽 클릭 → **모두 압축 풀기**. zip 안에서 바로 실행하지 마세요(아래 데이터 설명 참고).
2. 풀린 폴더의 `racoon-finder.exe`를 실행합니다.
3. "Windows의 PC 보호" 창이 뜨면 **추가 정보** → **실행**을 누릅니다. 서명하지 않은 데모라서 나오는 경고입니다.

설정과 작업 기록은 `racoon-finder.exe` 옆의 `data` 폴더에만 저장됩니다. 같은 폴더의 빈 `portable` 파일이 그렇게
하라는 표시라서, 지울 때는 앱을 끄고 폴더를 통째로 지우면 끝입니다.

### macOS 15

디스크 이미지(`RacoonFinder-demo-<버전>-macos-arm64.dmg`)와 zip 중 편한 쪽을 받습니다. 둘 다 같은 앱이 들어 있습니다.

1. dmg는 두 번 눌러 열고, 열린 창에서 `Racoon Finder.app`을 옆의 **Applications** 바로 가기로 끌어다 놓습니다(창에는
   `데모-안내.txt`도 있습니다). 다 옮겼으면 Finder 사이드바의 디스크 이미지 옆 꺼내기 단추를 누릅니다. zip은 엽니다(Safari는
   알아서 풀기도 합니다). `Racoon Finder.app`을 원하면 응용 프로그램 폴더로 옮깁니다. 새 판은 같은 방법으로 덮어 옮기면 됩니다.
2. 앱을 두 번 누릅니다. 공증하지 않은 데모라서 macOS가 열지 않고 경고 창을 띄웁니다. **완료**를 눌러 닫습니다.
3. **시스템 설정 → 개인정보 보호 및 보안**의 아래쪽에서 **그래도 열기**를 누르고, 한 번 더 묻는 창에서도
   **그래도 열기**를 누른 뒤 암호(또는 Touch ID)를 넣습니다. 그다음부터는 그냥 열립니다. (macOS 14 이하에서는 앱을
   Control-클릭(오른쪽 클릭) → **열기**로도 됩니다.)
4. 그래도 "손상되었기 때문에 열 수 없습니다"처럼 막히면 터미널에서 앱이 있는 폴더로 가서 실행한 뒤 다시 엽니다.

   ```sh
   xattr -dr com.apple.quarantine "Racoon Finder.app"
   ```

5. 데스크탑·문서·다운로드 폴더에 접근해도 되는지 물으면 **허용**을 누릅니다. 새 데모를 받을 때마다 다시 물을 수
   있습니다.

설정과 작업 기록은 `~/Library/Application Support/io.github.doguri25.RacoonFinder`에 저장됩니다.

**지우기:** 앱의 보기 메뉴(⌘J) ▸ 설정 맨 아래 **"Racoon Finder 완전 삭제…"**를 고릅니다. 지울 것의 목록과 "문서 폴더에 설정
백업" 체크박스(처음엔 꺼짐)가 있는 확인 창이 뜨고, 확인하면 앱이 바꿔 둔 것을 되돌리고 `Application Support`·`Caches`·`Logs`·
`Preferences`의 앱 폴더와 파일을 지운 뒤 앱을 휴지통으로 옮기고 끝납니다. 체크하면 `~/Documents/RacoonFinder-settings-backup.toml`
하나가 남습니다. 앱을 `/Applications`에 넣은 계정이 다르면 앱은 휴지통으로 옮기지 못한다고 알리고, 데이터만 지웁니다. 손으로
지우려면 앱과 위 폴더들, 그리고 `~/Library/Caches/`·`~/Library/Logs/` 아래의 같은 이름 폴더를 지웁니다.

### 데모로 해 볼 수 있는 것

0.1에서 하던 것(두 패널과 탭, 경로 줄, 즐겨찾기·드라이브·폴더 트리, 새 폴더·이름 바꾸기·휴지통·영구 삭제, 위치를 고르는
복사…·이동…, 앱 안의 끌어 놓기, 같은 이름 처리, 되돌리기·다시 실행, 작업 패널과 끊긴 작업 복구, 테마와 설정 기억)과
2판에서 더해진 것(아래 세 번째 목록)에, 3판에서 다른 앱과 주고받는 끌어 놓기와 Windows 메뉴가 더해졌고, 4판에서 아래의 것들이
더해졌습니다. 자세한 동작과 키는 [docs/ux/keyboard.md](docs/ux/keyboard.md)의 각 절에 있습니다.

#### 4판(0.4)에서 더해진 것

- **썸네일:** 아이콘 보기의 보통·크게·특대(보기 방식에 "특대 아이콘"이 새로 생겼습니다)에서 그림·동영상·문서의 미리 그림이 종류별 아이콘 자리에
  뜹니다. Windows는 탐색기와 같은 셸의 썸네일, macOS는 Quick Look의 썸네일을 쓰고, OS가 주지 않으면 앱이 그림 파일(PNG·JPG·
  GIF·WebP·BMP·ICO·TIFF)을 직접 줄여 보입니다. 목록은 아이콘으로 먼저 그려지고 썸네일은 도착하는 대로 바뀌며, 보이는 항목부터
  만듭니다. 한 파일에서 OS가 멈추거나 실패해도 그 파일만 아이콘으로 남고 창은 멈추지 않습니다. 만든 썸네일은 캐시 폴더에 256 MiB까지
  남아 다시 열 때 곧바로 뜹니다. 아이콘 크기는 Ctrl+휠(macOS ⌘+휠, 트랙패드 핀치)로 한 칸씩 바꿉니다. 보기 ▸ 설정의 "썸네일
  보이기"로 끌 수 있습니다.
- **즐겨찾기 고치기와 최근 폴더:** 즐겨찾기를 더하고 빼고 이름을 바꾸고 끌어서 순서를 바꿉니다(오른쪽 클릭 메뉴와 메뉴 키).
  폴더를 즐겨찾기 줄 사이나 빈 곳에 끌어 놓으면 즐겨찾기에만 더해지고 파일은 하나도 움직이지 않습니다(줄 한가운데에 놓으면 전처럼
  그 폴더로 이동·복사). 사이드바에는 최근에 연 폴더 열 개가 묶음으로 보입니다. 설정에 저장되어 다시 켜도 남습니다.
- **링크 만들기:** 항목 메뉴의 "링크 만들기 ▸"가 Windows는 바로 가기(`.lnk`)·심볼릭 링크·정션, macOS는 별칭·심볼릭 링크를 만듭니다
  (Linux는 심볼릭 링크). 같은 폴더에 만들고, Shift를 누른 채 고르면 다른 폴더를 고릅니다. 새 링크는 선택되고 알림과 Ctrl+Z로 되돌립니다.
  **되돌리기는 링크만 지우고 가리키던 대상은 어떤 경우에도 건드리지 않으며**, 그 자리가 이미 다른 것으로 바뀌었으면 거절합니다.
  Windows의 심볼릭 링크는 개발자 모드나 관리자 권한이 있어야 해서, 없으면 항목이 흐리게 보이고 까닭이 이름에 적힙니다.
- **마우스·트랙패드·터치:** 마우스 4번(뒤로)·5번(앞으로) 버튼이 키의 뒤로·앞으로와 같습니다. 목록의 항목이나 빈 곳을 0.5초 길게
  누르면(마우스 왼쪽 단추, 터치, 펜) 원이 차오르고 오른쪽 클릭 메뉴가 열립니다. 움직이면 취소되어 끌기·스크롤이 됩니다. 선택 메뉴(또는
  보기 ▸ 설정)의 "체크박스로 선택"을 켜면 항목 앞에 체크박스가 생겨 Ctrl 없이 하나씩 고르고, 자세히의 머리글 체크박스는 모두 선택·해제합니다.
- **되돌리기 기록과 상태 표시줄:** 작업 패널의 "되돌리기 기록"이 되돌릴 수 있는 작업과 다시 실행할 수 있는 작업을 시각과 함께
  줄로 보입니다. 맨 윗줄의 단추가 Ctrl+Z·Ctrl+Y와 같은 일을 하고, 항목이 사라지는 등 되돌리기 어려워진 줄은 흐려져 까닭이
  보입니다. 패널마다 아래의 상태 표시줄은 선택(개수와 크기), 항목 수, 거르기, 드라이브의 남은 공간을 폭에 맞춰 오른쪽부터 줄여 보입니다.
- **설정 버전과 백업:** 설정 파일에 버전이 들어 있어 앞으로의 판이 이어 읽습니다. 읽을 수 없는 설정 파일은 덮어쓰지 않고 같은
  폴더의 `settings.toml.bak-<시각>`으로 옮긴 뒤 기본값으로 시작하며, 창이 뜨면 알립니다.
- **설치와 제거:** Windows 설치 프로그램(내 계정에만 설치, 시작 메뉴 바로 가기, 알림의 보낸 이가 "Racoon Finder")과 제거 프로그램
  (앱의 `--cleanup`이 앱이 만든 것을 모두 지우고, 설정 백업을 고를 수 있음), macOS 디스크 이미지와 앱 안의 "완전 삭제…"(위
  "설치하기"와 "macOS 15"). 앱이 바꾼 OS 설정은 변경 원장에 적혀 있어서 지울 때 되돌립니다.

#### 3판(0.3)에서 더해진 것

- **다른 앱에서 끌어 오기:** 탐색기·Finder·바탕 화면 등에서 파일과 폴더를 목록의 폴더 행, 목록의 빈 곳, 탭, 트리의
  행에 끌어 놓습니다. 앱 안의 끌기처럼 놓을 곳이 강조되고 커서 옆에 "이동 → 폴더"·"복사 → 폴더"나 놓을 수 없는
  까닭이 뜹니다. 이동도 복사도 앱의 작업이 합니다(이름이 겹치면 묻고, 작업 패널에 보이고, 되돌릴 수 있습니다). 이동은
  복사를 마친 항목만 앱이 원본을 지우고, 끌어 온 앱에는 원본을 먼저 지우게 할 답을 주지 않습니다. 대화상자나 빠른 보기가
  떠 있는 동안에는 받지 않습니다. Linux(X11, 개발용)는 놓은 파일을 활성 패널의 폴더로 늘 복사합니다.
- **다른 앱으로 끌어내기(Windows·macOS):** 자세히의 행이나 아이콘·목록 보기의 항목을 창 밖으로 끌고 나가면 그때부터
  OS의 끌기가 되어 탐색기·Finder·바탕 화면·Dock의 휴지통·브라우저의 파일 올리기·메일 첨부에 놓을 수 있습니다. 받는
  앱이 OS 규칙대로 옮기거나 복사하고, 앱은 끌어낸 뒤 아무것도 지우지 않습니다. 창 밖으로 나갔다가 앱 창으로 돌아와
  놓으면 앱 안의 끌기처럼 놓입니다.
- **놓을 때의 동작:** 보조키가 정합니다. Windows는 탐색기처럼 Ctrl이 복사·Shift가 이동, macOS는 Finder처럼 ⌥이
  복사·⌘이 이동, Linux는 Ctrl이 복사·Shift가 이동입니다. 링크 키(Windows Alt, macOS ⌥⌘, Linux Ctrl+Shift)는 놓은
  폴더에 바로 가기(macOS 별칭, Linux 심볼릭 링크)를 만듭니다. 항목 메뉴의 "링크 만들기"로도 만들고, 되돌릴 수 있습니다. 보조키가 없으면 보기 ▸ 설정의 "끌어 놓기: 이동"(기본값)·"복사"·
  "OS 방식"(같은 드라이브면 이동, 다른 드라이브면 복사)·"매번 묻기"(놓은 자리에 여기로 이동·여기로 복사·취소 메뉴.
  끌기가 허용하지 않는 것은 빠집니다)를 따릅니다. 탐색기에서 오른쪽 버튼으로 끌어 놓아도 이 메뉴가 뜹니다. 커서 옆 문구와 커서 모양은 키를 누르거나 떼면
  마우스를 움직이지 않아도 바로 바뀝니다.
- **머무르면 열기와 자동 스크롤:** 끄는 동안 폴더 행, 다른 탭, 트리의 닫힌 폴더에 1초 머물면 그곳이 열리고 끌기는
  이어집니다. 목록과 트리의 끝(목록 보기는 왼쪽·오른쪽 끝)에 머물면 끝까지 굴러갑니다.
- **옮긴 뒤 되돌리기 알림:** 끌어서 옮기면 5초 동안 "항목 N개를 옮겼습니다 [되돌리기]"가 뜹니다. 보기 ▸ 설정의
  "끌어서 옮긴 뒤 되돌리기 알림"으로 끄면 뜨지 않고, Ctrl+Z(macOS ⌘Z)로는 여전히 되돌립니다.
- **Windows 메뉴:** Shift+오른쪽 클릭과 Shift+F10이 탐색기의 오른쪽 클릭 메뉴(Windows 11 탐색기의 "더 많은 옵션
  표시")를 띄웁니다: "보내기"·"연결 프로그램" 하위 메뉴와 7-Zip·Git 같은 셸 확장의 항목이 있습니다. 앱 메뉴 맨 아래의
  "더 많은 옵션 표시"도 같은 메뉴를 띄우고, 보기 ▸ 설정의 "오른쪽 클릭에 Windows 메뉴 바로 띄우기"를 켜면 오른쪽
  클릭과 메뉴 키가 앱 메뉴 대신 바로 띄웁니다. 그 메뉴의 이름 바꾸기·삭제·잘라내기·복사·붙여넣기는 앱 메뉴의 같은
  명령과 똑같이 앱이 합니다(이름 입력 창, 작업 엔진의 휴지통, 앱의 클립보드). 그래서 휴지통으로 가는 삭제와 이름
  바꾸기는 되돌릴 수 있고, Shift를 누른 채 고른 삭제(Shift+삭제)는 확인 창을 거친 뒤 영구 삭제라 되돌릴 수 없습니다.
- **공유(macOS):** 항목 메뉴의 "공유…"가 macOS의 공유 메뉴(AirDrop, 메일, 메시지 등)를 띄웁니다.

#### 2판(0.2)에서 더해진 것

- **화면 배치:** 듀얼 패널 켜기·끄기(F12, 끄면 한 패널 보기), 위아래로 나누기(Shift+F12), 두 패널 사이 분할선
  끌기(두 번 누르면 반반), 패널 바꾸기, 같은 폴더를 반대편에 열기(F9), 한쪽에서 폴더를 옮기면 반대편도 따라가는 탐색
  동기화(Shift+F9), 폴더 트리 보이기·숨기기. 배치는 다음 실행 때 그대로 돌아옵니다. 위아래로 나누기는 창이 900×560이면
  패널마다 3줄쯤 보이니 큰 창에서 씁니다.
- **탭:** 탭 메뉴(닫기, 다른 탭 닫기, 오른쪽 탭 닫기, 복제, 고정, 반대 패널로 옮기기), 닫은 탭 다시 열기, 끌어서 순서
  바꾸기와 반대 패널로 옮기기, 가운데 버튼으로 닫기. 고정한 탭은 다른 폴더로 갈 때 새 탭을 엽니다.
- **주소창:** 경로 조각 옆 `›`로 하위 폴더 목록을 열고, 경로를 칠 때는 하위 폴더 이름을 자동 완성합니다(Tab).
  `file:` 주소를 붙여넣어도 그 폴더로 갑니다.
- **보기와 열:** 자세히·목록·아이콘(작게·보통·크게, 4판에서 특대와 썸네일). 자세히의 열(크기, 수정한 날짜,
  만든 날짜, 종류, 확장자, 속성)을 보이고 숨기고, 끌어서 순서와 너비를 바꾸고, 글자에 맞춥니다. 2차 정렬과 "폴더 먼저",
  파일 확장자 숨기기. 보기는 폴더마다 기억하고 "하위 폴더에 적용"도 할 수 있습니다. 새로 고침(F5).
- **선택 도구:** 툴바의 **선택** 메뉴에서 모두 선택, 선택 해제, 선택 반전, 패턴으로 선택(`*.jpg;*.png` 같은 와일드카드나
  정규식), 같은 확장자 선택. 이 폴더에서 거르기 칸은 이름으로 목록을 좁힙니다.
- **미리 보기·빠른 보기:** 미리 보기 패널(Alt+P, macOS ⇧⌘P)과 빠른 보기(Space)가 이미지, 글(인코딩을 알아서 고름),
  폴더의 항목 수를 보입니다. 큰 파일도 창을 멈추지 않고, OneDrive·iCloud의 온라인 전용 파일은 내려받지 않습니다.
- **클립보드:** 탐색기·Finder와 파일을 주고받는 복사·잘라내기·붙여넣기(Ctrl+C·X·V, macOS ⌘C·⌘V, 옮겨 붙이기 ⌥⌘V).
  잘라낸 항목은 흐리게 보이고, 이름이 겹치면 `파일 (2).txt`로 붙이고, 붙여넣은 항목은 선택됩니다. 클립보드에 파일이
  없으면 메뉴의 붙여넣기가 꺼집니다. 경로 복사(Ctrl+Shift+C, macOS ⌥⌘C)는 전체 경로·이름만·따옴표 포함·UNC·슬래시·파일
  URL 여섯 형식입니다.
- **속성·체크섬:** 속성(Alt+Enter, macOS ⌘I)이 크기(폴더는 안을 모두 세어), 날짜, 속성, 링크 대상을 보이고, MD5·SHA-1·
  SHA-256·BLAKE3·xxHash3-64 체크섬을 계산해 복사하거나 붙여넣은 값과 비교합니다.
- **연결 프로그램·터미널·OS 속성 창:** 항목 메뉴의 "연결 프로그램으로 열기…", Windows의 "관리자 권한으로 실행", "터미널에서
  열기"(Shift+F4), "OS 속성 창 열기"(탐색기 속성 창, Finder 정보 가져오기).
- **작업 보고·알림·트레이:** 작업 패널의 "최근 완료"(복사 수, 건너뜀, 오류, 평균 속도, 걸린 시간)와 "로그 저장…". 10초
  넘게 걸린 작업이 창이 뒤에 있을 때 끝나면 OS 알림을 보냅니다. 작업 중에 창을 닫으면 "트레이에서 계속"(macOS는 메뉴
  막대)을 고를 수 있고, 앱을 다시 실행하면 새 창 대신 숨은 창이 돌아옵니다.
- **키보드:** 단축키를 OS별로 정했습니다. Windows는 파일 탐색기, macOS는 Finder와 같은 키이고, 듀얼 패널에만 있는 동작은
  두 쪽 모두 쓰지 않는 키를 받았습니다. 툴바 버튼의 툴팁과 메뉴 항목에 키가 보이고, 마우스로 하는 일은 거의 모두
  키보드로도 닿습니다(항목 메뉴는 메뉴 키, Linux는 Shift+F10도, macOS ⌃↩. 폴더 트리와 작업 패널은 F6). 한 열만의
  너비는 키로 정하지 않고 "모든 열 너비 맞추기"(Ctrl+Shift+=, macOS ⌃⌘=)로 글자에 맞춥니다.

### 0.4.0에서 알아 둘 점

- **서명하지 않은 설치 프로그램과 디스크 이미지:** Windows 설치 프로그램은 "PC 보호" 창을, macOS 디스크 이미지의 앱은 처음 열
  때 경고를 띄웁니다(위 "설치하기"와 "macOS 15"). 설치 프로그램은 서명이 없다는 점 말고는 평범한 사용자 단위 설치입니다.
- **0.3에서 올릴 때:** 0.3의 설정 파일을 그대로 읽고 다음 저장 때 설정 버전을 적습니다. 새 설정(썸네일 보이기, 길게 누르는 시간,
  체크박스로 선택, 즐겨찾기와 최근 폴더)은 기본값으로 시작합니다. 설정 파일을 읽을 수 없으면 `settings.toml.bak-<시각>`으로
  옮기고 기본값으로 시작합니다. 0.3.0 이하의 앱이 켜져 있으면 새 설치 프로그램과 제거 프로그램이 "끝내 달라"는 요청을 보내도 받지
  못합니다(30초 뒤 "앱이 아직 실행 중입니다"로 멈추니 앱을 먼저 끕니다).
- **썸네일은 실제 PC에서 처음 도는 코드입니다.** Windows는 셸에게, macOS는 Quick Look에게 묻는 부분을 Linux에서는 컴파일만
  검사했습니다. OS의 썸네일 생성기가 한 파일에서 멈추면 앱은 5초 뒤 그 파일을 포기하고 아이콘으로 두지만, 멈춘 스레드는 그 호출이
  끝날 때까지 남습니다(별도 프로세스로 격리하는 것은 다음 판). 폴더의 썸네일(안의 그림 몇 장)과 썸네일 전용 보기·크기 슬라이더는 없습니다.
- **두 손가락 스와이프로 뒤로·앞으로는 되지 않습니다.** 창 라이브러리(winit 0.30)가 데스크톱에서 이 제스처를 앱에 알리지 않습니다.
  뒤로·앞으로는 마우스 4·5번 버튼과 키로 합니다. 아이콘 크기의 핀치(macOS)와 Ctrl(⌘)+휠은 됩니다.
- **체크박스로 선택에는 키가 없습니다.** 선택 메뉴나 보기 ▸ 설정에서 켜고 끕니다.
- **링크:** 모든 링크는 만들 때의 대상 절대 경로를 가리켜서, 대상(이나 그 위 폴더)을 옮기면 끊어집니다. macOS 별칭은 Finder와
  별칭을 아는 앱만 따라가고, Windows 바로 가기는 탐색기가 따라갑니다. 정션은 로컬 드라이브의 폴더만 가리킵니다. 링크는 로컬
  디스크에서만 만들고, 하드 링크는 아직 없습니다. 그룹 정책으로 심볼릭 링크 권한을 받은 일반 사용자는 항목이 흐리게 보일 수 있습니다.
- **Windows 알림의 보낸 이:** 설치형은 "Racoon Finder"로 뜹니다. 압축만 푼 zip은 앱이 Windows에 이름을 등록하지 않아 "Windows
  PowerShell"로 뜹니다. 설치형에서 시작 메뉴의 Racoon Finder 바로 가기를 지우면 알림이 뜨지 않을 수 있습니다.
- **`--cleanup`:** 제거 프로그램이 부르는 명령입니다. 릴리즈 빌드는 콘솔 없는 프로그램이라 명령 프롬프트에서 직접 부르면 출력이
  보이지 않고 종료 코드(0 완료, 5 일부만 지움)만 남습니다.
- **완전 삭제(macOS)가 중간에 멈추면** 앱은 끝나지 않고 어디까지 했는지 보이는데, 이때 작업 엔진은 이미 끝나 있으므로 앱을 끝내고
  다시 실행해 남은 것부터 지웁니다. 지우는 동안 앱을 끝내는 길은 따로 막지 않았습니다.
- **작업 패널:** 되돌리기 기록이 있으면 패널 위에 머리 줄(약 40 px)이 늘 생깁니다. 작은 창(900×560)에서는 목록이 그만큼 줄어듭니다.
  작업이 끝난 직후에는 폴더 목록이 디스크보다 잠시 늦어 되돌릴 수 있는 줄이 잠깐 흐려질 수 있습니다.

### 0.3.0에서 알아 둘 점

- **끌어 놓기의 기본 동작은 이동입니다.** 보조키 없이 끌어 놓으면 다른 드라이브(USB 등)에서 끌어 온 것도 옮깁니다(끌어
  온 앱이 이동을 허용하지 않을 때만 복사). 복사가 끝난 뒤 앱이 원본을 지웁니다. 탐색기·Finder처럼 다른 드라이브에서는
  복사하려면 보기 ▸ 설정의 "끌어 놓기: OS 방식"을 고르거나, 놓을 때 Ctrl(macOS ⌥)을 누릅니다.
- **0.2에서 올릴 때:** 0.2의 설정 파일을 그대로 읽고, 새 설정은 기본값("끌어 놓기: 이동", 되돌리기 알림 켬, Windows 메뉴
  바로 띄우기 끔)으로 시작합니다.
- **Windows에서 끌어낸 동안과 Windows 메뉴가 떠 있는 동안:** 앱 창이 다시 그려지지 않습니다(그동안 OS의 루프가 돌고,
  창 라이브러리가 그리기를 미룹니다). 끌어낸 항목을 놓지 않고 앱 창으로 가져오면 커서 옆 문구, 놓을 곳의 강조,
  머무르면 열기, 자동 스크롤이 없습니다. 놓기는 되고, 끌기 그림 아래의 문구는 탐색기가 그려 보입니다.
- **macOS에서 끌어 오기:** 앱은 끌어 온 앱에 "이동"이라고 답하지 않습니다(그 앱이 원본을 먼저 지우지 않게). 그래서
  이동만 허용하는 앱에서 끈 것은 받지 않습니다. ⌃을 누른 채 끌면 금지 커서이고, 제목 막대 위에 놓은 파일은 활성 패널의
  폴더로 복사됩니다(위치와 보조키 없이).
- **앱 안의 오른쪽 버튼 끌기는 없습니다.** 창 라이브러리(Slint)의 끌기는 왼쪽 버튼으로만 시작합니다. 놓을 때마다 고르려면
  설정의 "끌어 놓기: 매번 묻기"를 씁니다. 탐색기에서 오른쪽 버튼으로 끌어 오는 것은 묻기 메뉴를 띄웁니다.
- **Windows 메뉴:** 셸 확장은 앱 안에서 돌기 때문에 잘못 만든 확장이 앱을 끝내거나 멈출 수 있습니다. Windows 11의 새
  메뉴에만 등록된 항목은 없을 수 있습니다(탐색기의 "더 많은 옵션 표시"와 같습니다). 폴더의 "열기"는 앱의 패널이 아니라
  탐색기 창으로 엽니다. 앱이 하지 않는 명령(속성, 보내기, 셸 확장 등)이 파일을 바꾸면 앱의 되돌리기에 남지 않습니다.
  "오른쪽 클릭에 Windows 메뉴 바로 띄우기"를 켠 동안에는 "연결 프로그램으로 열기…"와 "관리자 권한으로 실행"을 Windows
  메뉴 자신의 항목으로 합니다(앱의 메뉴가 뜨지 않고, 두 명령에는 키가 없습니다).
- **새 판의 zip을 새 폴더에 풀면(Windows):** 설정과 작업 기록은 `racoon-finder.exe` 옆의 `data` 폴더에 있으므로, 새
  폴더의 앱은 처음 실행처럼 빈 설정으로 시작합니다. 탭, 배치, 창 크기를 이어 쓰려면 두 앱을 모두 끈 뒤 예전 폴더의
  `data` 폴더를 새 폴더의 `racoon-finder.exe` 옆에 통째로 복사하고(새 폴더에 `data`가 이미 있으면 바꿉니다) 새 앱을
  실행합니다. macOS는 설정이 앱 밖(`~/Library/Application Support/…`)에 있어 앱만 바꾸면 이어집니다.
- **0.1에서 바로 올릴 때:** 끝나지 않은 작업을 모두 끝내거나 다음 실행의 복구 창에서 버린 뒤 새 판으로 바꾸세요. 0.1(또는
  2판 개발 중의 이전 빌드)은 복사를 되돌릴 때 휴지통에 넣지 못한 복사본을 평범한 영구 삭제 작업으로 지웠습니다. 그 작업이
  작업 기록에 끝나지 않은 채 남아 있다가 새 판의 복구 창에서 "다시 실행"을 고르면, 새 판의 복사본 지우기와 달리 복사본이
  그사이 바뀌었는지 다시 확인하지 않고 지웁니다.
- **Windows 알림의 보낸 이(zip):** 압축만 푼 zip은 앱이 Windows에 자기 이름을 등록하지 않으므로, 작업 완료 알림에는
  보낸 이로 "Windows PowerShell"이 보입니다. 설치 프로그램으로 설치한 앱은 "Racoon Finder"로 뜹니다.
- **macOS의 ⌘Q, 앱 메뉴의 종료, Dock의 종료:** 묻지 않고 앱을 끝냅니다. 창의 닫기 버튼과 같은 순서로 설정을 저장하고 진행
  중인 작업을 멈춘 뒤 끝나며, 멈춘 작업은 다음 실행의 복구 창에 나옵니다. 메뉴 막대로 숨긴 동안에도 같습니다. 작업이 도는
  중에 "끝낼까요?"를 묻고 "메뉴 막대에서 계속"을 고르려면 ⌘Q 대신 창의 닫기 버튼(숨긴 동안에는 메뉴 막대 아이콘의
  "끝내기")을 씁니다. (macOS가 앱을 끝내는 길에서는 묻는 창을 띄울 수 없습니다.)
- **macOS에서 숨은 창 되찾기:** 메뉴 막대로 숨긴 창은 Dock 아이콘을 누르거나 Finder에서 앱을 다시 열어도 돌아오지
  않습니다(macOS가 실행 중인 앱에 보내는 "다시 열기"를 지금의 창 라이브러리가 앱에 알리지 않습니다). 메뉴 막대 아이콘의
  "창 열기"(또는 아이콘 클릭)를 쓰거나, 터미널에서 `open -n "/Applications/Racoon Finder.app"`처럼 한 번 더 실행합니다.

### 실제 PC에서 손으로 확인할 것

자동 테스트는 Linux와 CI의 Windows·macOS 러너에서 돕니다. 실제 OS 창, 메뉴, 클립보드, 알림, 다른 앱과의 끌어 놓기가
걸린 일은 Windows 11과 macOS 15에서 손으로 확인합니다. 자세한 단계는 [docs/ux/keyboard.md](docs/ux/keyboard.md)의 각
절에 있고, 아래의 번호는 그 절의 "손으로 확인할 것" 번호입니다.

#### 먼저: 링크를 지우고 되돌려도 원본이 남는지

4판에서 가장 먼저 봅니다. 링크를 만들고 되돌리거나 지울 때 링크가 가리키는 폴더와 파일을 잃으면 안 됩니다. 연습용 폴더에서 합니다.

- [ ] **Windows·macOS, 링크 만들기를 되돌리고 링크를 지우기:** 파일이 든 연습 폴더와 파일 하나에서 항목 메뉴의 "링크 만들기"로 각
  종류를 만듭니다(Windows: 바로 가기·정션·심볼릭 링크, macOS: 별칭·심볼릭 링크). 만든 링크를 **되돌리기(Ctrl+Z, macOS ⌘Z)**하면
  링크만 없어지고 원본 폴더의 파일과 원본 파일은 그대로이고, 다시 실행하면 같은 이름으로 다시 생기는지. 이어서 링크를 만들고 **휴지통으로
  지우기**(Delete, macOS ⌘⌫)도 해서 링크만 휴지통에 가고 원본은 그대로인지(정션과 폴더 심볼릭 링크는 안을 따라가 지워서는 안 됩니다).
  되돌리기 전에 링크를 직접 지우고 같은 이름의 보통 파일을 만든 뒤 되돌리면 파일은 그대로고 "링크가 바뀌었거나…" 알림이 뜨는지.
  ([링크 만들기](docs/ux/keyboard.md#링크-만들기-ops-08) 1·2·4·6번)

#### 먼저: 원본이 남는지

다음 세 줄은 파일을 잃는지에 걸린 일이라 이어서 봅니다. macOS에서는 넷째 줄(투명한 뷰)을 먼저 봅니다. 그것이 안
되면 둘째 줄의 끌기가 앱의 받기에 오지 않습니다.

- [ ] **Windows, 탐색기에서 Shift를 누른 채 앱으로 끌어 이동:** 놓은 직후에도, 앱의 복사가 끝나기 전에는 탐색기 쪽
  원본이 그대로 있습니다(탐색기가 원본을 스스로 지우지 않습니다). 복사가 끝난 뒤 앱의 작업이 원본을 지웁니다. 큰
  파일(수 GB), 작은 파일 여러 개, 폴더 하나로 한 번씩. 탐색기가 원본을 먼저 지우면 데이터를 잃는 문제이니 바로 알려
  주세요. ([끌어 놓기](docs/ux/keyboard.md#끌어-놓기-dnd) 11번)
- [ ] **macOS, Finder에서 앱으로 끌어 이동(⌘을 누른 채, 그리고 키 없이 "끌어 놓기: 이동"으로):** 놓은 자리에서 끌기
  그림이 사라지고 Finder로 미끄러져 돌아가지 않습니다. 앱의 이동 작업이 도는 동안 Finder는 원본을 지우지 않고(Finder
  창에 그대로 있습니다), 복사가 끝난 뒤 앱의 작업이 원본을 지웁니다. 큰 파일, 작은 파일 여러 개, 폴더 하나로 한 번씩.
  매번 묻기로 놓으면 끌기 그림이 Finder로 돌아가고, 메뉴에서 고르기 전에는 원본이 그대로입니다. Finder가 원본을 먼저
  지우면 바로 알려 주세요. ([끌어 놓기](docs/ux/keyboard.md#끌어-놓기-dnd) 20번)
- [ ] **Windows·macOS, 앱에서 다른 앱으로 끌어낸 뒤:** 앱은 아무것도 지우지 않습니다. 탐색기·Finder 창, 바탕 화면, Dock의
  휴지통, 브라우저의 파일 올리기, 메일 첨부 어디에 놓아도 앱의 작업 패널에 작업이 생기지 않고, 앱의 목록은 폴더 감시로만
  바뀝니다. 다른 드라이브로 Shift를 누른 채 놓아 옮길 때 원본은 탐색기가 옮겨 사라지거나 그대로 남을 뿐, 앱이 지우지
  않습니다. 올리기·첨부 뒤에는 원본이 그대로입니다. ([끌어 놓기](docs/ux/keyboard.md#끌어-놓기-dnd) 28~30번, 33~35번)
- [ ] **macOS, 창 내용 위의 투명한 뷰가 끌기를 받는지:** Finder에서 파일을 끌어 목록의 폴더 행 위에 머물면 커서 옆
  문구("이동 → 폴더")와 행의 강조 테두리가 보이고, 놓으면 그 폴더로 옮겨집니다. 같은 창에서 클릭, 두 번 클릭, 휠,
  트랙패드 스크롤, 오른쪽 클릭 메뉴, 행·탭 끌기, 경로 입력의 I자 커서와 글자 입력이 전과 같고, 창이 전처럼(빈 곳이나
  깜박임 없이) 그려집니다. 문구와 강조가 없고 놓은 파일이 활성 패널의 폴더로 복사되면 뷰가 끌기를 받지 못하는 것이니
  macOS 판과 함께 알려 주세요. 클릭이나 휠이 창에 닿지 않으면 바로 알려 주세요. ([끌어 놓기](docs/ux/keyboard.md#끌어-놓기-dnd) 18번)

#### Windows

- [ ] **탐색기 → 앱:** 목록의 폴더 행, 목록의 빈 곳, 탭, 트리의 행에 각각 끌어 놓기. 키 없이는 설정대로(기본은 이동),
  Ctrl은 복사, Shift는 이동, Alt는 "링크 만들기: 폴더"와 링크 커서(놓으면 바로 가기)이고, 커서 모양·끌기 그림 아래 문구·앱의
  커서 옆 문구가 서로 맞는지. 오른쪽 버튼으로 끌어 놓으면 묻기 메뉴, 다른 드라이브(USB)는 OS 방식에서 복사, 놓은 뒤
  작업 하나와 이동의 되돌리기 알림. 머무는 곳마다 앱 안 끌기와 같은 강조 테두리가 보이고, 지나간 뒤 트리에 마우스
  표시가 남지 않는지. ([끌어 놓기](docs/ux/keyboard.md#끌어-놓기-dnd) 10번, 17번)
- [ ] **배율과 모니터:** 배율 150%·125%인 화면과 주 모니터 왼쪽의 보조 모니터에서 강조되는 곳과 놓이는 곳이 커서
  아래의 행인지. ([끌어 놓기](docs/ux/keyboard.md#끌어-놓기-dnd) 12번)
- [ ] **트레이에서 돌아온 창, 대화상자, 파일이 아닌 끌기:** 트레이로 숨겼다 다시 보인 창이 그대로 받는지. 대화상자(새
  폴더 이름, 확인, 충돌, 속성)나 빠른 보기가 떠 있으면 금지 커서이고 놓아도 아무 일이 없는지. 브라우저의 글자·이미지는
  끄는 내내 금지 커서인지. ([끌어 놓기](docs/ux/keyboard.md#끌어-놓기-dnd) 13~15번)
- [ ] **탐색기에서 끈 채 자동 스크롤:** 목록·트리의 끝에 마우스를 멈추고 있으면 끝까지 굴러가고, 강조와 커서 옆 문구가
  커서 아래 행을 따라가고, 창 밖으로 나가거나 놓으면 바로 멈추는지. ([끌어 놓기](docs/ux/keyboard.md#끌어-놓기-dnd) 16번)
- [ ] **압축 파일 안에서 끌어 오기:** 탐색기의 zip 폴더 안과 7-Zip 창에서 끌어 놓으면 복사되거나, 끌어 온 프로그램이
  임시 파일을 먼저 지웠으면 작업 완료 보고가 처리하지 못한 항목으로 알리는지(어느 쪽이었는지 적어 주세요). 압축 파일과
  다른 파일은 그대로인지. ([끌어 놓기](docs/ux/keyboard.md#끌어-놓기-dnd) 41번)
- [ ] **앱 → 탐색기·바탕 화면:** 목록 보기의 행과 아이콘 보기의 항목에서 각각, 창 밖으로 나가는 순간 셸의 끌기 그림이
  커서를 따라가는지(그림이 없으면 적어 주세요). 같은 드라이브면 이동, 다른 드라이브면 복사, Ctrl은 복사, Shift는 이동.
  폴더 여러 개와 파일을 함께 끌어도 같은지. ([끌어 놓기](docs/ux/keyboard.md#끌어-놓기-dnd) 28~29번)
- [ ] **끌어낸 뒤 앱 창으로 돌아오기, 그만두기:** 반대 패널에 놓으면 앱 안 끌기와 같은 동작이 한 번만 일어나는지. 돌아온
  동안 앱 창이 다시 그려지는지(그려지면 알려 주세요. 위 "알아 둘 점"을 고칩니다)와 끄는 동안의 CPU 사용량. Esc로
  그만두거나 작업 표시줄에 놓으면 아무 일도 없고, 그 뒤 클릭·끌기·다음 끌어내기가 전과 같은지.
  ([끌어 놓기](docs/ux/keyboard.md#끌어-놓기-dnd) 31~32번)
- [ ] **Windows 메뉴:** 파일 하나·여러 개·폴더·빈 곳의 Shift+오른쪽 클릭과 Shift+F10, 앱 메뉴의 "더 많은 옵션 표시",
  "보내기"·"연결 프로그램" 하위 메뉴와 아이콘, 7-Zip·Git 같은 셸 확장, 메뉴의 삭제(Ctrl+Z로 되돌리기, Shift는 영구
  삭제 확인)·이름 바꾸기·잘라내기·복사·붙여넣기가 앱의 명령이 되는지, "속성" 창이 앱 앞에 뜨는지, 설정 "오른쪽 클릭에
  Windows 메뉴 바로 띄우기", 배율·왼쪽 모니터에서 메뉴의 자리, 메뉴 밖 클릭·Esc, 이름에 `;`·`&`·`%`·한글·괄호가 든
  항목. ([Windows 메뉴와 macOS 공유](docs/ux/keyboard.md#windows-메뉴와-macos-공유-ops-05) 1~11번)

- [ ] **썸네일(탐색기와 비교):** 사진 폴더를 보기 방식 ▸ 특대 아이콘으로 엽니다. JPG·PNG·HEIC(확장 설치 시)·MP4·PDF·DOCX의 그림이
  탐색기와 같은 그림으로 오고, 투명한 PNG는 투명하게, 텍스트 파일은 종류별 아이콘으로 남는지. 손상된 JPG와 0바이트 파일이 있어도
  창이 멈추지 않는지. ([썸네일 공급자](docs/ux/keyboard.md#썸네일-공급자-view-09) 1·3·4번)
- [ ] **링크(바로 가기·정션·심볼릭 링크):** 파일의 "링크 만들기 ▸ 바로 가기"가 "이름 - 바로 가기.lnk"를 만들어 선택하고 탐색기에서
  열리는지(한 번 더 만들면 "(2)"). 폴더의 정션이 앱에서 더블클릭으로 들어가지고 파일에는 정션 항목이 없는지. 개발자 모드를 끄고 일반
  권한으로 켠 앱에서 "심볼릭 링크" 항목이 흐리고 까닭이 이름에 보이며 누르면 알림만 뜨는지, 개발자 모드를 켜고 앱을 다시 켜면 파일·폴더에서
  각각 만들어지는지. ([링크 만들기](docs/ux/keyboard.md#링크-만들기-ops-08) 1~3번)
- [ ] **마우스 4·5번 버튼, 터치·펜 길게 누르기, 정밀 터치패드:** 폴더를 두어 번 들어간 뒤 4번이 거슬러 올라가고 5번이 내려오는지(경로
  칸 편집·대화상자·끌기 중에는 아무 일도 없는지). 터치 화면과 펜으로 항목을 길게 누르면 원이 차고 메뉴가 열리고, 8 px 넘게 움직이면
  스크롤·끌기가 되고, 손가락을 떼도 항목이 열리지 않는지. 마우스 왼쪽 단추를 길게 눌러 메뉴를 연 뒤 단추를 떼도 첫 항목이 실행되지
  않고 다음 클릭이 평소 같은지("오른쪽 클릭에 Windows 메뉴 바로 띄우기"를 켜면 Windows 메뉴가 뜸). 정밀 터치패드의 두 손가락 가로
  스와이프가 가로 휠로 오는지 적어 주세요(뒤로·앞으로는 안 됨). ([마우스·트랙패드](docs/ux/keyboard.md#마우스트랙패드-길게-누르기-체크박스-선택-nav-04-comp-04-pick-02-nav-15) 1~4번)
- [ ] **제거 프로그램 열기:** 설치형 앱에서 보기 ▸ 설정 맨 아래 "제거 프로그램 열기"가 보이고 제거 프로그램이 뜨는지, 포터블 zip으로
  푼 앱에는 항목이 없는지, 900×560 창에서 설정 하위 메뉴가 이 항목까지 잘리지 않는지.
  ([앱 지우기](docs/ux/keyboard.md#앱-지우기-inst-0405) 5번)

#### Windows 설치 프로그램

- [ ] **설치:** `RacoonFinder-setup-…-windows-x64.exe`(ARM PC는 `-arm64.exe`)를 실행합니다. 관리자 확인 창이 뜨지 않고,
  `%LOCALAPPDATA%\Programs\RacoonFinder`에 `racoon-finder.exe`만 설치되며(`portable` 파일이 없습니다), 시작 메뉴에
  Racoon Finder가 생기고, 설치 마지막 화면의 "Racoon Finder 실행"으로 앱이 열리는지.
- [ ] **알림의 보낸 이:** 설치한 앱에서 알림이 뜨는 일(예: 큰 복사 작업이 끝날 때)을 하고, 알림 위쪽의 보낸 이가
  "Racoon Finder"(앱 아이콘 포함)로 보이는지. 시작 메뉴에서 연 경우와 설치 직후 "실행"으로 연 경우 둘 다.
- [ ] **덮어 설치(업그레이드):** 앱을 켜 둔 채 이전 버전 설치 프로그램으로 설치한 뒤 새 버전을 실행합니다. 설치 프로그램이
  앱을 닫고 덮어쓰며, 설치된 앱 목록에 항목이 하나뿐이고, 설정과 작업 기록이 그대로인지.
- [ ] **지우기, 백업 없이:** 설정 → 앱에서 지울 때 "설정을 백업할까요?"에 **아니요**. 문서 폴더에 백업 파일이 생기지 않는지.
- [ ] **지우기, 백업과 함께:** 다시 설치해 설정을 바꾼 뒤 지우면서 **예**. 문서 폴더에 `RacoonFinder-settings-backup.toml`
  하나가 생기고 바꾼 설정이 들어 있는지. 앱이 켜져 있어도 지우기가 앱을 끄고 진행하는지.
- [ ] **지운 뒤:** `%APPDATA%\RacoonFinder`, `%LOCALAPPDATA%\RacoonFinder`, `%LOCALAPPDATA%\Programs\RacoonFinder`,
  시작 메뉴(과 고른 경우 바탕 화면)의 바로 가기, 설치된 앱 목록의 항목이 모두 없는지.
- [ ] **`--cleanup` 계획과 실행 중인 작업:** 큰 복사를 돌리는 중에 제거를 시작하면 앱 창에 평소 닫을 때와 같은 질문이 뜨는지(답하지
  않으면 30초 뒤 제거 프로그램이 "아직 실행 중"이라고 알림). 제거 뒤 `%LOCALAPPDATA%\RacoonFinder\cache\thumbs`(썸네일 캐시)도 없는지.
- [ ] **zip과 함께:** 설치형을 쓰는 PC에 zip을 푼 폴더가 있어도(그 폴더의 `data`와 `portable` 포함) 설치와 삭제가 그 폴더를
  건드리지 않는지.

#### macOS

- [ ] **Finder → 앱:** 목록의 폴더 행, 목록의 빈 곳, 탭, 트리의 행에 각각 끌어 놓기. 키 없이는 설정대로(기본은 이동),
  ⌥은 복사(+ 커서), ⌘은 이동, ⌥⌘은 "링크 만들기: 폴더"와 링크 커서(놓으면 별칭). 끄는 도중 키를 누르고 떼면 마우스를
  움직이지 않아도 커서 모양과 커서 옆 문구가 함께 바뀌는지. ⇧은 동작을 바꾸지 않고 ⌃은 금지 커서인지. 다른 볼륨(USB)은
  OS 방식에서 복사, 놓은 뒤 작업 하나와 이동의 되돌리기 알림. ([끌어 놓기](docs/ux/keyboard.md#끌어-놓기-dnd) 19번)
- [ ] **화면과 창:** Retina 화면과 Retina가 아닌 외부 화면, 주 화면의 왼쪽과 위의 보조 화면, 창 크기를 바꾸거나 전체
  화면으로 한 뒤에도 강조되는 곳과 놓이는 곳이 커서 아래의 행인지. 메뉴 막대로 숨겼다 다시 연 창이 그대로 받는지.
  ([끌어 놓기](docs/ux/keyboard.md#끌어-놓기-dnd) 21~22번)
- [ ] **대화상자, Safari의 글자, 자동 스크롤, 제목 막대, VoiceOver:** 대화상자나 빠른 보기가 떠 있으면 금지 커서이고
  끌기 그림이 Finder로 돌아가는지. Safari의 글자·링크는 끄는 내내 금지 커서인지. Finder에서 끈 채 목록·트리 끝에
  머물면 굴러가는지. 제목 막대 위에 놓으면 활성 패널의 폴더로 복사되는지. VoiceOver로 창의 목록과 버튼을 읽고 누르는
  것이 전과 같은지. ([끌어 놓기](docs/ux/keyboard.md#끌어-놓기-dnd) 23~27번)
- [ ] **앱 → Finder·Dock의 휴지통:** 목록 보기의 행과 아이콘 보기의 항목에서 각각, 창 밖으로 나가는 순간 항목들의
  아이콘이 커서를 따라가는지. 같은 볼륨이면 이동, 다른 볼륨(USB)이면 복사, ⌥은 복사(+ 커서), ⌘은 이동인지. 휴지통에
  놓으면 Finder가 휴지통으로 옮기는지. ([끌어 놓기](docs/ux/keyboard.md#끌어-놓기-dnd) 33~34번)
- [ ] **끌어낸 뒤 앱 창으로 돌아오기:** 반대 패널에 놓으면 앱 안 끌기와 같은 동작이 한 번만 일어나는지. 돌아온 동안
  배지와 강조가 보이고, 이동이면 커서가 이동 화살표(+가 아님), ⌥을 누르면 +인지. Esc로 그만두면 아무 일도 없는지.
  ([끌어 놓기](docs/ux/keyboard.md#끌어-놓기-dnd) 36번)
- [ ] **공유…:** 항목 하나·여러 개의 "공유…"가 그 자리 아래에 공유 메뉴를 띄우고 AirDrop·메일로 보낼 수 있는지(이름에
  한글이 든 파일도 같은 파일이 첨부되는지). 빈 곳 메뉴에는 "공유…"가 없는지. ([Windows 메뉴와 macOS 공유](docs/ux/keyboard.md#windows-메뉴와-macos-공유-ops-05) 12번)

- [ ] **디스크 이미지 설치:** `RacoonFinder-demo-<버전>-macos-arm64.dmg`를 열면 `Racoon Finder.app`, `Applications` 바로 가기,
  `데모-안내.txt`가 보이고, 앱을 Applications로 끌어 놓으면 복사되고, 꺼낸 뒤 앱이 열리는지(처음에는 경고 → "그래도 열기").
  새 판의 dmg로 한 번 더 덮어 옮겨도 열리는지.
- [ ] **썸네일(Quick Look):** 특대 아이콘으로 연 사진 폴더에서 JPG·PNG·HEIC·MP4·PDF·Keynote의 그림이 Finder와 같게 오는지.
  투명한 PNG의 가장자리가 어둡게 번지지 않는지, 손상된 JPG와 0바이트 파일이 있어도 창이 멈추지 않는지, Quick Look이 앱 번들에서
  동작하는지(그림이 안 오고 앱 자체 디코더의 그림만 오면 알려 주세요). 핀치와 ⌘+휠로 크기 단계가 바뀌는지.
  ([썸네일 공급자](docs/ux/keyboard.md#썸네일-공급자-view-09) 2~4번)
- [ ] **별칭:** 파일과 폴더의 "링크 만들기 ▸ 별칭"이 "이름 별칭"을 만들고 Finder가 더블클릭으로 원본을 여는지(원본을 옮겨도 따라가는지),
  되돌리기 뒤 별칭만 없어지는지. 마우스 4·5번 버튼이 macOS에서 뒤로·앞으로로 오는지. ([링크 만들기](docs/ux/keyboard.md#링크-만들기-ops-08) 4번)
- [ ] **완전 삭제…:** `/Applications`의 앱에서 보기 ▸ 설정 맨 아래의 "Racoon Finder 완전 삭제…"가 목록과 체크박스가 있는 창을 띄우고
  취소하면 아무것도 바뀌지 않는지. 체크를 켜고 지우면 앱이 끝나고 `~/Documents/RacoonFinder-settings-backup.toml`이 생기며(한 번 더 하면
  `-2`), `~/Library/Application Support|Caches|Logs/io.github.doguri25.RacoonFinder`와 `~/Library/Preferences`의 plist가 없고 휴지통에
  앱이 있는지(꺼내서 다시 실행하면 처음 실행처럼 열림). 복사 작업을 돌려 둔 채 고르면 작업이 진행 중이라는 두 번째 질문이 뜨고, 다른 계정이
  넣은 앱이면 데이터만 지우고 "직접 휴지통으로 옮겨 주세요"가 뜨는지. ([앱 지우기](docs/ux/keyboard.md#앱-지우기-inst-0405) 1~4번)

#### 두 OS 모두

- [ ] **링크의 나머지:** 종류를 Shift를 누른 채 고르면 대상 폴더 선택 창이 뜨고 고른 폴더에 링크가 생기는지(메뉴 키로 연 메뉴에서는
  Shift+Enter). 원본을 지운 뒤 심볼릭 링크·바로 가기를 만들면 "대상이 없는 링크"로 알리는지. 끌어 놓을 때 링크 키(Windows Alt 또는 Ctrl+Shift,
  macOS ⌥⌘)를 누르면 놓은 폴더에 링크가 생기는지(Alt를 뗀 뒤 Windows 시스템 메뉴가 뜨지 않는지).
  ([링크 만들기](docs/ux/keyboard.md#링크-만들기-ops-08) 5~7번)
- [ ] **즐겨찾기와 최근 폴더:** 탐색기·Finder에서 폴더를 즐겨찾기 줄 사이로 끌어 놓으면 가로줄이 보이고 그 자리에 들어가며 원본은
  그대로인지, 같은 폴더를 또 놓아도 두 번 들어가지 않는지, 줄 한가운데에 놓으면 그 폴더로 이동·복사되는지. 줄을 끌어 순서를 바꾸고
  오른쪽 클릭 메뉴와 메뉴 키로 각 항목을 하고, 앱을 다시 켜도 목록이 그대로인지. 폴더를 돌아다닌 뒤 최근 폴더가 최근 것이 위로 열 개까지
  쌓이고, 지운 폴더는 흐리게 보이며 누르면 없다고 알리는지. ([즐겨찾기와 최근 폴더](docs/ux/keyboard.md#즐겨찾기와-최근-폴더-nav-05-dnd-01) 1~4번)
- [ ] **썸네일의 성능과 캐시:** 사진 1000장 폴더를 특대로 열어 끝까지 빠르게 스크롤해도 창이 멈추지 않고 멈춘 자리의 썸네일이 먼저 오는지,
  다시 열면(앱을 다시 켜도) 곧바로 오고 파일을 고치면 새 썸네일이 오는지, Ctrl+휠(⌘+휠, 핀치)로 크기가 한 칸씩 바뀌며 목록이 스크롤하지
  않는지, 보기 ▸ 설정의 "썸네일 보이기"를 끄면 모두 아이콘으로 돌아오는지. 100 MB JPG 한 장의 시간을 재 주세요.
  ([썸네일](docs/ux/keyboard.md#썸네일-view-09-nav-06-아이콘-크기-comp-04) 1~5번)
- [ ] **되돌리기 기록과 상태 표시줄:** 이름 바꾸기 둘과 이동 하나 뒤 작업 패널에 "되돌리기 기록 3개"가 접힌 채 보이고, 펼치면 최근 것이 위로
  있고 맨 윗줄에만 켜진 "되돌리기"가 있는지, 그 단추가 Ctrl+Z와 같은지. 이름을 바꾼 항목을 탐색기·Finder에서 지우면 몇 초 안에 그 줄이
  흐려지는지(macOS는 한글 이름으로도: 멀쩡한 줄이 흐려지면 안 됨). F6 → ↓ → Enter로 키보드만으로 펼쳐지고 화면 읽기 프로그램이 읽는지.
  900×560의 두 패널에서 선택과 거르기를 건 상태창이 오른쪽부터 줄어드는지(시스템 글꼴을 키운 Windows 125%·150%도).
  ([되돌리기 기록](docs/ux/keyboard.md#되돌리기-기록-ops-12) 1~4번, [상태 표시줄](docs/ux/keyboard.md#상태-표시줄-nav-12))
- [ ] **체크박스로 선택:** 자세히·목록·아이콘(보통·크게)에서 체크박스로 하나씩 고르고 머리글 체크박스로 모두 고르고 풀 수 있는지, 켠 채
  앱을 다시 켜도 그대로인지, 화면 읽기 프로그램이 "…선택, 체크 상자"로 읽는지, 보기 ▸ 설정이 900×560 창에서 잘리지 않는지.
- [ ] **깨진 설정 파일:** 앱을 끄고 설정 파일(`settings.toml`, 위 "설정과 작업 기록" 폴더)을 텍스트 편집기로 깨뜨린 뒤 켭니다. 창이 뜬 다음
  "설정 파일을 읽을 수 없어 백업하고 기본값으로 시작했습니다" 알림이 뜨고, 같은 폴더에 `settings.toml.bak-<시각>`이 생기며 깨진 내용이
  그대로 들어 있는지. 설정을 바꾸고 껐다 켜면 새 파일에 남는지.
- [ ] **이름에 한글·공백·`#`·`%`가 든 파일 끌어내기:** 받는 앱이 같은 이름의 파일을 받는지(macOS는 NFC와 NFD 이름
  둘 다). ([끌어 놓기](docs/ux/keyboard.md#끌어-놓기-dnd) 37번)
- [ ] **끄는 동안 오른쪽 버튼·Esc:** 행을 끄는 동안 오른쪽 버튼을 누르면(Windows는 Shift를 누른 채로, 설정 "오른쪽
  클릭에 Windows 메뉴 바로 띄우기"를 켜고도) 끌기가 놓기 없이 끝나고 메뉴가 뜨지 않는지. 그 뒤 버튼을 놓고 창 밖으로
  나가 바탕 화면·탐색기·Finder 위로 가거나 반대 패널을 눌러도 아무것도 옮겨지지 않는지. 끄는 동안 Shift+F10·메뉴
  키·F10(macOS ⌃↩·⌘J)이 메뉴를 띄우지 않는지. Esc는 끌기만 그만두고 고른 항목은 그대로인지.
  ([끌어 놓기](docs/ux/keyboard.md#끌어-놓기-dnd) 39~40번)
- [ ] **앱 안 끌기의 보조키와 설정:** 반대 패널의 폴더 위로 끈 채 Ctrl(macOS ⌥)을 누르고 떼면 마우스를 움직이지
  않아도 커서 옆 문구와 커서 모양이 "복사"와 "이동" 사이에서 바뀌는지. 링크 키는 금지 커서이고 놓아도 아무 일이
  없는지(macOS의 ⌃·⇧은 동작을 바꾸지 않는지). "끌어 놓기: OS 방식"(같은 드라이브는 이동, USB는 복사), "매번 묻기"
  메뉴(취소·Esc·바깥 클릭은 아무 일도 없고, 닫힌 뒤 키가 목록에 돌아오는지), 다시 실행해도 설정이 남는지.
  ([끌어 놓기](docs/ux/keyboard.md#끌어-놓기-dnd) 1~5번)
- [ ] **머무르면 열기, 자동 스크롤, 되돌리기 알림:** 폴더 행·다른 탭·트리의 닫힌 폴더에 1초 머물면 열리고 그 안에 놓을
  수 있는지, 1초 전에 옮기면 열리지 않는지. 목록·트리 끝에서 끝까지 굴러가는지. 끌어서 옮기면 5초 동안 "항목 N개를
  옮겼습니다 [되돌리기]"가 뜨고 단추가 되돌리는지, 설정에서 끄면 뜨지 않는지. ([끌어 놓기](docs/ux/keyboard.md#끌어-놓기-dnd) 6~8번)
- [ ] **Linux(X11, 개발용):** 파일 관리자의 파일을 창에 놓으면 활성 패널의 폴더로 복사되고(여러 파일은 작업 하나),
  행을 창 밖으로 끌고 나가도 OS의 끌기가 시작되지 않는지. ([끌어 놓기](docs/ux/keyboard.md#끌어-놓기-dnd) 9번, 38번)

#### 2판에서 이어지는 확인

- [ ] **OS 메뉴(Windows·macOS는 메뉴가 OS 메뉴입니다):** 보기 메뉴(F10, macOS ⌘J) ▸ 배치에서 한 패널 보기일 때 "같은
  폴더를 반대편에"·"탐색 동기화"·분할선 항목이 꺼져 보이는지, 위아래로 나누기에서 분할선 항목 이름이 "분할선을
  위로"·"분할선을 아래로"인지, 보기 메뉴에 "폴더 트리로 가기 (F6)"가 있는지. 항목 메뉴와 빈 곳 메뉴의 "붙여넣기"가
  메모장·TextEdit에서 글자를 복사한 뒤에는 꺼지고 탐색기·Finder에서 파일을 복사한 뒤에는 켜지는지.
  ([보기](docs/ux/keyboard.md#보기-nav-06070810), [배치](docs/ux/keyboard.md#배치와-탐색-동기화-lay-010205))
- [ ] **탐색기·Finder와 클립보드:** 탐색기·Finder에서 복사·잘라낸 파일을 앱에 붙여넣기, 앱에서 복사·잘라낸 파일을
  탐색기·Finder에 붙여넣기, Esc로 잘라내기 취소, 같은 폴더에 붙여넣으면 `(2)`, macOS의 ⌘C 뒤 ⌥⌘V는 옮기기, 경로 복사와
  UNC 경로, 붙여넣은 항목이 선택되는지.
  ([클립보드](docs/ux/keyboard.md#클립보드-dnd-1011-ops-07)의 "손으로 확인할 것" 9가지)
- [ ] **알림과 트레이:** 10초 넘는 복사를 창을 뒤에 둔 채 끝내면 OS 알림(macOS는 처음에 허용을 묻습니다), 작업 중 창 닫기 →
  "트레이에서 계속", 트레이 메뉴의 모두 일시정지·계속·끝내기, 숨은 동안 생긴 질문이나 실패로 창이 돌아오기, 숨긴 채 앱을
  다시 실행하면 숨은 창이 돌아오기. ([작업 완료 보고, 알림, 트레이](docs/ux/keyboard.md#작업-완료-보고-알림-트레이-xfer-1415)의
  "손으로 하는 점검" 12가지)
- [ ] **터미널·연결 프로그램·UAC·OS 속성 창:** `;`, `&`, `$`, `%`, 한글이 든 폴더에서 "터미널에서 열기"(Shift+F4)가 그
  폴더에서 열리는지, "연결 프로그램으로 열기…", Windows의 "관리자 권한으로 실행"과 UAC 창, 탐색기 속성 창과 Finder 정보
  가져오기 창(macOS는 처음에 Finder 제어 허용을 묻습니다), 이 창들이 앱 앞에 뜨는지.
  ([연결 프로그램, 터미널, OS 속성 창](docs/ux/keyboard.md#연결-프로그램-터미널-os-속성-창-ops-040611)의 11가지)
- [ ] **macOS ⌘Q와 Dock의 종료:** 큰 복사 중에 ⌘Q(그리고 다른 실행에서 Dock 아이콘의 종료)를 누르면 앱이 묻지 않고 끝나고,
  다음 실행에서 탭과 창 크기가 그대로이며 멈춘 복사가 복구 창에 나오는지. 메뉴 막대로 숨긴 동안의 ⌘Q도 같은지.
  ([작업 완료 보고, 알림, 트레이](docs/ux/keyboard.md#작업-완료-보고-알림-트레이-xfer-1415))
- [ ] **한국어 입력기로 조합하기:** Windows의 Microsoft 입력기와 macOS의 두벌식으로 경로 입력(자동 완성 목록이 뜬 채로),

- [ ] **한국어 입력 소스를 켠 채 글자로 고르기:** 목록에서 한글이나 영문을 치면 그 글자로 시작하는 항목으로 가는지.

- [ ] **OneDrive·iCloud의 온라인 전용 파일:** 미리 보기·빠른 보기, 속성(폴더 크기 포함), 체크섬이 그 파일을 내려받지
