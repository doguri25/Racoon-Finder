# Racoon-Finder

Windows 11과 macOS 15에서 쓰는 두 패널 파일 관리자입니다. 아직 개발 중입니다.

## 데모 실행

개발 중인 데모를 내 PC에서 직접 써 볼 수 있습니다. `main`과 `feat/…` 브랜치에 커밋이 올라올 때마다
GitHub Actions의 **Demo build**가 OS별 실행 파일을 만듭니다. 설치 프로그램은 아직 없고, 서명·공증을 하지
않은 데모라서 처음 열 때 OS가 경고합니다.

> **주의:** 데모는 진짜 파일을 옮기고 지웁니다. 처음에는 연습용 폴더에서 써 보세요. 예를 들어 바탕 화면에
> `연습` 폴더를 만들고 아무 파일이나 복사해 넣은 뒤, 그 안에서만 옮기고 지워 봅니다.

### 내려받기

1. GitHub에 로그인합니다. Actions 산출물은 로그인해야 내려받을 수 있습니다.
2. 이 저장소의 **Actions** 탭 → 왼쪽 목록의 **Demo build** → 초록 체크 표시가 붙은 최근 실행을 엽니다.
3. 아래쪽 **Artifacts**에서 내 PC에 맞는 파일을 내려받습니다. 산출물은 30일 동안 남아 있습니다.

| PC | 파일 |
| --- | --- |
| Windows 11 (대부분의 PC) | `RacoonFinder-demo-windows-x64.zip` |
| Windows 11 ARM (Snapdragon 등) | `RacoonFinder-demo-windows-arm64.zip` |
| Apple 실리콘 Mac (M1 이후) | `RacoonFinder-demo-macos-arm64.zip` |
| Linux x64 (개발용) | `RacoonFinder-demo-linux-x64.tar.gz` |

Windows에서 어느 쪽인지 모르겠으면 설정 → 시스템 → 정보의 "시스템 종류"를 봅니다("x64 기반 프로세서" 또는
"ARM 기반 프로세서"). Intel Mac용 데모는 아직 없습니다. 압축 파일 안의 `데모-안내.txt`에 같은 안내가 짧게 들어
있습니다.

### Windows 11

1. 내려받은 zip을 오른쪽 클릭 → **모두 압축 풀기**. zip 안에서 바로 실행하지 마세요(아래 데이터 설명 참고).
2. 풀린 폴더의 `racoon-finder.exe`를 실행합니다.
3. "Windows의 PC 보호" 창이 뜨면 **추가 정보** → **실행**을 누릅니다. 서명하지 않은 데모라서 나오는 경고입니다.

설정과 작업 기록은 `racoon-finder.exe` 옆의 `data` 폴더에만 저장됩니다. 같은 폴더의 빈 `portable` 파일이 그렇게
하라는 표시라서, 지울 때는 앱을 끄고 폴더를 통째로 지우면 끝입니다.

### macOS 15

1. 내려받은 zip을 엽니다(Safari는 알아서 풀기도 합니다). `Racoon Finder.app`을 원하면 응용 프로그램 폴더로 옮깁니다.
2. 앱을 두 번 누릅니다. 공증하지 않은 데모라서 macOS가 열지 않고 경고 창을 띄웁니다. **완료**를 눌러 닫습니다.
3. **시스템 설정 → 개인정보 보호 및 보안**의 아래쪽에서 **그래도 열기**를 누르고, 한 번 더 묻는 창에서도
   **그래도 열기**를 누른 뒤 암호(또는 Touch ID)를 넣습니다. 그다음부터는 그냥 열립니다. (macOS 14 이하에서는 앱을
   Control-클릭(오른쪽 클릭) → **열기**로도 됩니다.)
4. 그래도 "손상되었기 때문에 열 수 없습니다"처럼 막히면 터미널에서 앱이 있는 폴더로 가서 실행한 뒤 다시 엽니다.

   ```sh
   xattr -dr com.apple.quarantine "Racoon Finder.app"
   ```

5. 데스크탑·문서·다운로드 폴더에 접근해도 되는지 물으면 **허용**을 누릅니다. 새 데모를 받을 때마다 다시 물을 수
   있습니다.

설정과 작업 기록은 `~/Library/Application Support/io.github.doguri25.RacoonFinder`에 저장됩니다. 지울 때는 앱과 이
폴더, 그리고 `~/Library/Caches/`와 `~/Library/Logs/` 아래의 같은 이름 폴더를 지웁니다.

### 데모로 해 볼 수 있는 것

- **둘러보기:** 좌우 두 패널과 패널마다 여러 탭. 경로 줄의 폴더 이름을 누르거나 경로를 직접 입력해 이동하고,
  왼쪽에는 즐겨찾기, 드라이브와 남은 공간, 지금 보는 폴더를 따라가는 폴더 트리가 있습니다. 다른 프로그램이
  파일을 바꾸면 목록에 바로 나타납니다. 열 머리글로 정렬하고, 파일을 두 번 누르면 기본 앱으로 엽니다.
- **파일 다루기:** 새 폴더, 이름 바꾸기, 휴지통으로 보내기, 영구 삭제(확인한 뒤에만). 툴바, 오른쪽 클릭 메뉴,
  단축키로 할 수 있습니다.
- **복사…·이동…:** 어디로 보낼지 고르는 창이 뜹니다. 반대편 패널, 열린 탭, 최근 위치, 즐겨찾기에서 고르거나
  경로를 입력하고, 그 자리에서 새 폴더를 만들 수도 있습니다. 옮기는 폴더 안처럼 갈 수 없는 곳은 고를 수 없게
  표시합니다.
- **끌어 놓기:** 항목을 다른 패널, 탭, 트리의 폴더로 끌어 놓으면 이동합니다. Ctrl(macOS는 ⌘)을 누른 채 놓으면
  복사합니다.
- **같은 이름이 있을 때:** 덮어쓰기, 건너뛰기, 이름 바꿔 둘 다 두기 중에서 고릅니다(폴더끼리는 덮어쓰기 대신
  합치기). 복사·이동 창에서 미리 정해 둘 수도 있습니다.
- **되돌리기·다시 실행:** 이동, 복사, 휴지통, 이름 바꾸기, 새 폴더를 되돌립니다. 덮어쓴 파일과 영구 삭제한
  파일은 되돌릴 수 없습니다.
- **작업 패널:** 진행률, 속도, 남은 시간을 보여 주고 일시정지와 취소를 할 수 있습니다. 작업 중에 앱이 꺼졌다면
  다음 실행 때 이어서 할지 버릴지 묻습니다.
- **보기와 기억:** **보기** 버튼에서 밝게, 어둡게, 시스템 설정 따르기와 숨김 파일 보기를 고릅니다. 창 크기, 탭,
  테마, 숨김 파일 설정은 다음 실행 때 그대로 돌아옵니다.

자주 쓰는 단축키입니다. macOS에서는 Ctrl 대신 ⌘, Alt 대신 Option을 누릅니다. Mac 키보드의 delete 키는
Backspace(상위 폴더)라서 휴지통으로 보내려면 fn+delete를 누르고, F2·F5 같은 기능 키도 fn과 함께 누릅니다.
⌘H(앱 가리기)는 macOS가 먼저 가져가므로 숨김 파일은 Finder처럼 ⌘⇧.(마침표)로 켜고 끕니다(**보기** 버튼에서도
됩니다). ⌘Space는 Spotlight가 가져가므로 하나씩 고를 때는 ⌘-클릭을 씁니다.

| 키 | 하는 일 |
| --- | --- |
| Tab | 왼쪽·오른쪽 패널 바꾸기 |
| Enter / Backspace, Alt+↑ | 열기 / 상위 폴더 |
| Alt+← / Alt+→ | 뒤로 / 앞으로 |
| Shift+↑↓, Ctrl+Space, Ctrl+A, Esc | 범위 선택, 하나씩 선택, 모두 선택, 선택 해제 |
| F2 | 이름 바꾸기 |
| Delete / Shift+Delete | 휴지통으로 보내기 / 영구 삭제 |
| F5 / F6 | 복사… / 이동… |
| F7, Ctrl+Shift+N | 새 폴더 |
| Ctrl+Z / Ctrl+Y | 되돌리기 / 다시 실행 |
| Ctrl+T / Ctrl+W | 새 탭 / 탭 닫기 |
| Ctrl+L | 경로 입력 |
| Ctrl+H (macOS는 ⌘⇧.) | 숨김 파일 보기 |
| 글자 입력 | 그 글자로 시작하는 항목으로 이동 |

### 아직 없는 것

- 설치 프로그램, 코드 서명과 공증(그래서 처음 열 때 경고가 뜹니다), Intel Mac용 데모
- 툴바의 거르기 칸, 아이콘·썸네일 보기, 열 추가와 너비 조절, 폴더마다 다른 보기 설정
- 위아래 분할, 창 여러 개, 패널마다 따로 쓰는 폴더 트리, 화면 배치 저장
- 탐색기·Finder와 주고받는 끌어 놓기와 복사·붙여넣기, OS의 오른쪽 클릭 메뉴, 속성 창, 경로 복사
- 휴지통 안 보기, 네트워크 위치, 클라우드 동기화 상태
- 주소 자동 완성, 마우스의 뒤로·앞으로 버튼, 길게 눌러 메뉴 열기, 한국어 외의 언어
