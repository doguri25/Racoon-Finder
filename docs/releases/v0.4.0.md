Racoon Finder **데모 4판(0.4.0)**입니다. Windows 11과 macOS 15에서 쓰는 듀얼 패널 파일 관리자를 개발하고 있고, 이 판은 내 PC에 설치해서 직접 써 보는 데모입니다. Windows 설치 프로그램과 macOS 디스크 이미지가 처음으로 함께 올라왔습니다. 설치 프로그램, 디스크 이미지, 압축 파일 모두 서명·공증을 하지 않았습니다. 그래서 처음 열 때 OS가 경고합니다. 여는 방법은 [README의 "데모 실행"](https://github.com/doguri25/Racoon-Finder/blob/v0.4.0/README.md#데모-실행)에 있습니다.

> **주의:** 데모는 진짜 파일을 옮기고 지웁니다. 처음에는 연습용 폴더에서 써 보세요. 링크 만들기와 설치·제거("완전 삭제")도 처음에는 연습용 폴더와 연습용 PC에서 해 봅니다.

## 내려받기

이 릴리즈에는 일곱 파일이 있습니다.

| PC | 파일 |
| --- | --- |
| Windows 11 (대부분의 PC), 설치 프로그램 | `RacoonFinder-setup-0.4.0-windows-x64.exe` |
| Windows 11 ARM (Snapdragon 등), 설치 프로그램 | `RacoonFinder-setup-0.4.0-windows-arm64.exe` |
| Windows 11 (대부분의 PC), 압축만 풀면 되는 zip | `RacoonFinder-demo-windows-x64.zip` |
| Windows 11 ARM, 압축만 풀면 되는 zip | `RacoonFinder-demo-windows-arm64.zip` |
| Apple 실리콘 Mac (M1 이후), 디스크 이미지 | `RacoonFinder-demo-0.4.0-macos-arm64.dmg` |
| Apple 실리콘 Mac (M1 이후), 압축 파일 | `RacoonFinder-demo-macos-arm64.zip` |
| Linux x64 (개발용) | `RacoonFinder-demo-linux-x64.tar.gz` |

- **Windows 설치 프로그램:** 내 계정에만 설치합니다(관리자 권한 없음, `%LOCALAPPDATA%\Programs\RacoonFinder`). 서명이 없어서 "Windows의 PC 보호" 창이 뜨면 **추가 정보** → **실행**을 누릅니다. 지울 때는 설정 → 앱 → 설치된 앱에서 지우면 되고, 설정 백업을 할지 묻습니다.
- **macOS 디스크 이미지:** 열어서 앱을 **Applications**로 끌어다 놓습니다. 공증하지 않아서 처음에는 경고가 뜨니 시스템 설정 → 개인정보 보호 및 보안에서 **그래도 열기**를 누릅니다. 지울 때는 앱 안의 보기 ▸ 설정 맨 아래 "Racoon Finder 완전 삭제…"를 씁니다.
- **zip과 tar.gz:** 전 판과 같습니다. 설정은 Windows zip에서는 `data` 폴더에, macOS에서는 `~/Library/…`에 둡니다.

## 먼저 확인해 주세요: 링크를 지우고 되돌려도 원본이 남는지

- **Windows·macOS:** 링크 만들기(바로 가기·정션·심볼릭 링크, macOS는 별칭·심볼릭 링크)를 되돌리거나 만든 링크를 휴지통으로 지워도 링크만 사라지고, 링크가 가리키던 폴더와 파일은 그대로 남아야 합니다. 정션과 폴더 심볼릭 링크는 안을 따라가 지워서는 안 됩니다. 원본이 하나라도 사라지면 바로 알려 주세요.
- **Windows·macOS:** 되돌리기 전에 링크를 지우고 같은 이름의 보통 파일을 만든 뒤 되돌리면 그 파일은 그대로 있고 "링크가 바뀌었거나…" 알림이 떠야 합니다.

나머지 확인 목록은 [README의 "실제 PC에서 손으로 확인할 것"](https://github.com/doguri25/Racoon-Finder/blob/v0.4.0/README.md#실제-pc에서-손으로-확인할-것)에 있습니다.

## 4판에서 더해진 것

- **썸네일:** 아이콘 보기의 보통·크게·특대(새로 생김)에서 그림·동영상·문서의 미리 그림이 뜹니다. Windows는 셸, macOS는 Quick Look의 썸네일을 쓰고, OS가 주지 않으면 앱이 그림 파일을 직접 줄여 보입니다. 목록을 막지 않고 보이는 항목부터 만들며, 한 파일에서 OS가 멈추거나 실패해도 그 파일만 아이콘으로 남습니다. Ctrl+휠(macOS ⌘+휠, 핀치)로 크기를 한 칸씩 바꿉니다.
- **즐겨찾기와 최근 폴더:** 즐겨찾기를 더하고 빼고 이름을 바꾸고 끌어서 순서를 바꿉니다. 폴더를 즐겨찾기 줄 사이나 빈 곳에 끌어 놓으면 즐겨찾기에만 더해지고 파일은 움직이지 않습니다. 사이드바에 최근 폴더 열 개가 보입니다.
- **링크 만들기:** 항목 메뉴의 "링크 만들기 ▸"가 Windows는 바로 가기·심볼릭 링크·정션, macOS는 별칭·심볼릭 링크를 만듭니다. 알림과 Ctrl+Z로 되돌립니다. 되돌리기는 링크만 지우고 대상은 건드리지 않습니다.
- **마우스·트랙패드·터치:**
  - 마우스 4번·5번 버튼이 뒤로·앞으로입니다.
  - 항목을 길게 누르면(마우스 왼쪽 단추, 터치, 펜) 오른쪽 클릭 메뉴가 열립니다.
  - "체크박스로 선택"을 켜면 항목 앞의 체크박스로 하나씩 고릅니다.
- **되돌리기 기록과 상태 표시줄:** 작업 패널에 되돌릴 수 있는 작업과 다시 실행할 수 있는 작업이 시각과 함께 줄로 보이고, 패널마다 선택·항목 수·거르기·남은 공간이 상태 표시줄에 보입니다.
- **설정 버전과 백업:** 설정 파일에 버전이 들어 있고, 읽을 수 없는 설정은 `settings.toml.bak-<시각>`으로 옮긴 뒤 기본값으로 시작하며 알립니다.
- **설치와 제거:** Windows 설치 프로그램(시작 메뉴 바로 가기, 알림의 보낸 이가 "Racoon Finder", 제거 때 앱이 만든 것을 모두 지우고 설정 백업 선택), macOS 디스크 이미지와 "완전 삭제…".
- 1판부터 3판까지의 기능(두 패널과 탭, 복사·이동·휴지통·되돌리기, 보기와 열, 빠른 보기, 클립보드, 속성·체크섬, 트레이, 다른 앱과 주고받는 끌어 놓기, Windows 메뉴, macOS 공유 등)은 그대로입니다.

## 알아 둘 점

- **서명 없음:** 설치 프로그램, 디스크 이미지, 압축 파일 모두 서명·공증을 하지 않았습니다.
- **0.3에서 올릴 때:** 0.3의 설정 파일을 그대로 읽습니다. 0.3.0 이하의 앱이 켜져 있으면 새 설치 프로그램이 "끝내 달라"는 요청을 보내도 받지 못하니, 앱을 먼저 끄세요.
- **썸네일은 실제 PC에서 처음 도는 코드입니다.** OS의 생성기가 멈추면 앱은 5초 뒤 그 파일을 포기하지만 멈춘 스레드는 호출이 끝날 때까지 남습니다. 폴더의 썸네일, 썸네일 전용 보기와 크기 슬라이더는 없습니다.
- **두 손가락 스와이프로 뒤로·앞으로는 되지 않습니다.** 창 라이브러리가 데스크톱에서 이 제스처를 알리지 않습니다. 마우스 4·5번 버튼과 키를 쓰세요.
- **링크:** 대상의 절대 경로를 가리키므로 대상을 옮기면 끊어집니다. macOS 별칭은 Finder 같은 앱만 따라갑니다. Windows 심볼릭 링크는 개발자 모드나 관리자 권한이 있어야 만듭니다. 하드 링크는 없습니다.
- **완전 삭제(macOS)가 중간에 멈추면** 앱이 어디까지 했는지 보이고, 앱을 끝내고 다시 실행해 남은 것부터 지웁니다.
- **아직 없는 것:** 하드 링크, 썸네일 전용 보기, 폴더 썸네일, 생성기 격리, 압축해서 넣기, 탐색기 대신 쓰기와 상주 모드, 코드 서명과 공증, Intel Mac, winget·Homebrew.

자세한 내용은 [README](https://github.com/doguri25/Racoon-Finder/blob/v0.4.0/README.md)와 [키 설명서](https://github.com/doguri25/Racoon-Finder/blob/v0.4.0/docs/ux/keyboard.md)에 있습니다.
