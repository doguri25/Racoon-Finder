Racoon Finder **데모 5판(0.5.0)**입니다. Windows 11과 macOS 15에서 쓰는 듀얼 패널 파일 관리자를 개발하고 있고, 이 판은 내 PC에 설치해서 직접 써 보는 데모입니다. 이 판에서 휴지통을 폴더처럼 보고 복원·비우기를 하고, 고대비 테마와 표시 밀도·글자 크기를 고르고, 앱을 영어로도 쓸 수 있습니다. 설치 프로그램, 디스크 이미지, 압축 파일 모두 서명·공증을 하지 않았습니다. 그래서 처음 열 때 OS가 경고합니다. 여는 방법은 [README의 "데모 실행"](https://github.com/doguri25/Racoon-Finder/blob/v0.5.0/README.md#데모-실행)에 있습니다.

> **주의:** 데모는 진짜 파일을 옮기고 지웁니다. 처음에는 연습용 폴더에서 써 보세요. 휴지통 보기의 "휴지통 비우기…"와 "영구 삭제…"는 OS의 진짜 휴지통에서 지우고 되돌릴 수 없으니, 휴지통에 살릴 것이 없는지 먼저 봅니다.

## 내려받기

이 릴리즈에는 일곱 파일이 있습니다.

| PC | 파일 |
| --- | --- |
| Windows 11 (대부분의 PC), 설치 프로그램 | `RacoonFinder-setup-0.5.0-windows-x64.exe` |
| Windows 11 ARM (Snapdragon 등), 설치 프로그램 | `RacoonFinder-setup-0.5.0-windows-arm64.exe` |
| Windows 11 (대부분의 PC), 압축만 풀면 되는 zip | `RacoonFinder-demo-windows-x64.zip` |
| Windows 11 ARM, 압축만 풀면 되는 zip | `RacoonFinder-demo-windows-arm64.zip` |
| Apple 실리콘 Mac (M1 이후), 디스크 이미지 | `RacoonFinder-demo-0.5.0-macos-arm64.dmg` |
| Apple 실리콘 Mac (M1 이후), 압축 파일 | `RacoonFinder-demo-macos-arm64.zip` |
| Linux x64 (개발용) | `RacoonFinder-demo-linux-x64.tar.gz` |

- **Windows 설치 프로그램:** 내 계정에만 설치합니다(관리자 권한 없음, `%LOCALAPPDATA%\Programs\RacoonFinder`). 이 판부터 Windows의 표시 언어를 따라 영어나 한국어로 뜹니다(그 밖의 언어는 English가 골라진 언어 선택 창). 0.4.0 위에 덮어 설치하면 앞의 언어인 한국어를 따릅니다. 서명이 없어서 "Windows의 PC 보호" 창이 뜨면 **추가 정보** → **실행**을 누릅니다.
- **macOS 디스크 이미지:** 열어서 앱을 **Applications**로 끌어다 놓습니다. 공증하지 않아서 처음에는 경고가 뜨니 시스템 설정 → 개인정보 보호 및 보안에서 **그래도 열기**를 누릅니다.
- **zip과 tar.gz:** 전 판과 같습니다. 설정은 Windows zip에서는 `data` 폴더에, macOS에서는 `~/Library/…`에 둡니다.

## 먼저 확인해 주세요: 다시 시도는 실패한 것만, 휴지통 비우기는 센 것만

- **Windows·macOS:** "처리하지 못한 항목" 창의 **다시 시도**는 실패한 항목만 다시 해야 합니다. 성공한 파일(그 뒤에 대상에서 고친 파일도)을 다시 쓰거나 두 번 옮기면 안 되고, 되돌리기 기록에는 원래 작업과 다시 시도한 작업이 따로 남아야 합니다.
- **Windows·macOS:** 휴지통 보기의 **휴지통 비우기…**와 **영구 삭제…**는 확인 창(항목 수와 "되돌릴 수 없습니다")을 거친 뒤에만, 그 창이 센 항목만 지워야 합니다. 질문을 띄운 채 탐색기·Finder에서 파일을 하나 더 휴지통에 넣으면 그 파일은 남아야 합니다. 복원은 원래 자리에 같은 이름이 있으면 덮어쓰지 않고 물어야 합니다.
- 다른 일이 일어나면 바로 알려 주세요.

나머지 확인 목록은 [README의 "실제 PC에서 손으로 확인할 것"](https://github.com/doguri25/Racoon-Finder/blob/v0.5.0/README.md#실제-pc에서-손으로-확인할-것)에 있습니다.

## 5판에서 더해진 것

- **전송의 남은 선택:** 이름이 겹칠 때 "더 새 파일만"과 "크기가 다를 때만" 덮어쓰기(위치 고르기 창과 이름 충돌 창), 실패한 항목만 다시 하는 "다시 시도", 실패할 때마다 다시 시도·건너뛰기·중단을 묻는 설정, 복사할 때 링크가 가리키는 것을 복사하기.
- **작업 패널과 떠 있는 작업 창:** 지금 처리하는 파일 이름과 속도 그래프, 대기 중인 작업의 순서 바꾸기(단추와 키), 작업 패널을 별도 창으로 띄우기(보기 ▸ 작업 패널 ▸ 별도 창).
- **기본 작업의 남은 조각:** 새 파일(빈 텍스트 파일), 이름 바꾸기 창의 Tab으로 다음 항목, 선택된 이름을 천천히 한 번 더 눌러 이름 바꾸기, 뒤로·앞으로 버튼의 방문 기록 메뉴(Alt+↓, macOS ⌥⌘↓), 위치 고르기 창의 경로 자동 완성·새 폴더 키·최근 위치에서 시작하기.
- **화면 배치:** 패널마다 따로 쓰는 폴더 트리, 툴바 숨기기, 창의 위치·크기·최대화 기억.
- **보기:** 크기 슬라이더가 있는 썸네일 보기(64~512px), 타일 보기, 접근한 날짜·경로 열.
- **휴지통과 내 PC:** 사이드바의 휴지통에서 원래 위치·삭제한 날짜를 보고 복원·위치를 골라 꺼내기·영구 삭제·비우기. 내 PC는 드라이브와 남은 공간을 타일로 보입니다.
- **테마:** 테마가 토큰 파일이 되었고, 고대비 테마(검정 바탕, 흰 글자, 노랑 강조, 색 말고 모양으로도 알림)가 더해졌습니다. OS의 고대비를 켜면 시스템 설정 따르기도 고대비가 됩니다.
- **표시 밀도와 글자 크기:** 촘촘하게·보통·넉넉하게와 90~130%를 따로 고르고, 바로 바뀝니다(보기 ▸ 테마).
- **한국어·English:** 앱의 모든 말이 두 언어로 있습니다. 보기 ▸ 테마 맨 아래의 "언어: …"로 고르고(기본은 OS 언어), 다시 시작하면 바뀝니다. 번역 방법은 [docs/i18n.md](https://github.com/doguri25/Racoon-Finder/blob/v0.5.0/docs/i18n.md)에 있습니다.
- 1판부터 4판까지의 기능(두 패널과 탭, 복사·이동·휴지통·되돌리기, 보기와 열, 빠른 보기, 클립보드, 속성·체크섬, 트레이, 다른 앱과 주고받는 끌어 놓기, Windows 메뉴, macOS 공유, 썸네일, 링크 만들기, 설치·제거 등)은 그대로입니다.

## 알아 둘 점

- **서명 없음:** 설치 프로그램, 디스크 이미지, 압축 파일 모두 서명·공증을 하지 않았습니다.
- **0.4에서 올릴 때:** 0.4의 설정 파일을 그대로 읽고 설정 버전 2로 옮깁니다. 숨긴 폴더 트리는 숨긴 채로 열리고, 새 설정은 기본값으로 시작합니다. 언어도 기본값(시스템 설정 따르기)이라 OS의 언어가 한국어가 아니면 영어로 뜹니다: 보기 ▸ 테마의 "언어: 한국어"를 고르고 다시 시작합니다.
- **휴지통 비우기는 질문이 센 항목만 하나씩 지웁니다(모든 OS).** 질문 뒤에 휴지통에 들어온 것은 남고, 그사이 바뀐 항목은 지우지 않습니다. 복원은 덮어쓰지 않습니다.
- **휴지통의 OS별 차이:** macOS는 원래 위치를 알 수 없어 휴지통 보기의 복원이 꺼져 있고 "위치를 골라 꺼내기…"로 꺼냅니다(앱이 보낸 항목은 ⌘Z로 돌아옵니다). "위치를 골라 꺼내기…"는 모든 OS에서 같은 드라이브(볼륨)의 폴더로만 꺼냅니다(USB의 휴지통 항목은 그 USB의 폴더로). 전체 디스크 접근 권한이 없으면 휴지통을 읽지 못할 수 있고, iCloud Drive의 휴지통은 보이지 않고 비우지도 않습니다. Windows에서 영구 삭제·비우기 뒤 휴지통 아이콘이 바로 바뀌는지는 아직 확인하지 못했습니다. 휴지통은 변경 알림이 없어 창이 앞으로 올 때와 F5에 다시 읽습니다.
- **떠 있는 작업 창은 뜰 때 키보드를 가져갑니다.** 주 창을 누르거나 Esc·Tab·F6으로 돌아옵니다. 주 창에 딸린 창이 아니라서 겹치면 뒤로 가고, 위치와 크기는 저장하지 않습니다.
- **고대비와 메뉴:** Windows·macOS의 메뉴는 OS의 메뉴라 앱의 테마와 글자 크기가 아니라 OS의 모양을 따르고(앱에서 고대비를 골라도 OS가 밝게면 메뉴는 밝습니다. 스크롤바는 앱의 테마를 따릅니다), Linux의 메뉴는 키보드가 놓인 항목을 색으로만 알려 고대비에서 잘 보이지 않습니다. 다음 계획이 앱이 그리는 메뉴로 바꿉니다.
- **언어는 다시 시작해야 바뀝니다.** 날짜와 숫자는 두 언어 모두 같은 꼴입니다. 영어 창은 Linux에서만 찍어 보았습니다.
- **작업 패널의 높이:** 작은 창(900×560)에서 대기 중인 작업과 최근 완료가 함께 보이면 목록이 몇 줄만 남습니다. 별도 창으로 띄우거나 최근 완료를 접습니다.
- **창 위치는 실제 PC에서 처음 도는 코드입니다.** Wayland는 크기와 최대화만 돌아옵니다.
- **아직 없는 것:** 창 여러 개, 권한 상승 보조 프로세스(UAC), 탐색기 대신 쓰기와 상주 모드, 다시 시작 없는 언어 전환, 언어에 맞춘 날짜·숫자, 앱이 그리는 메뉴, 하드 링크, 압축해서 넣기, 폴더 썸네일, 코드 서명과 공증, Intel Mac, winget·Homebrew.
