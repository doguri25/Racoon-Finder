Racoon Finder **데모 3판(0.3.0)**입니다. Windows 11과 macOS 15에서 쓰는 듀얼 패널 파일 관리자를 개발하고 있고, 이 판은 내 PC에서 직접 써 보는 데모입니다. 설치 프로그램은 없고 서명·공증도 하지 않았습니다. 그래서 처음 열 때 OS가 경고합니다. 여는 방법은 [README의 "데모 실행"](https://github.com/doguri25/Racoon-Finder/blob/v0.3.0/README.md#데모-실행)에 있습니다.

> **주의:** 데모는 진짜 파일을 옮기고 지웁니다. 처음에는 연습용 폴더에서 써 보세요. 다른 앱과 주고받는 끌어 놓기는 실제 PC에서 처음 써 보는 기능입니다.

## 3판에서 더해진 것

- **다른 앱에서 끌어 오기**
  - 탐색기·Finder·바탕 화면에서 끌어 온 파일을 커서 아래의 폴더 행, 빈 곳, 탭, 트리에 놓습니다.
  - 이동도 복사도 앱의 작업이 합니다. 이름이 겹치면 묻고, 작업 패널에 보이고, 되돌릴 수 있습니다.
  - 이동하면 복사를 마친 뒤에만 원본을 지웁니다.
- **다른 앱으로 끌어내기(Windows·macOS)**
  - 항목을 창 밖으로 끌고 나가 탐색기·Finder·바탕 화면·브라우저 파일 올리기·메일 첨부에 놓습니다.
  - 앱은 끌어낸 뒤 아무것도 지우지 않습니다.
- **놓을 때의 동작**
  - 보조키가 정합니다. Windows는 Ctrl이 복사, Shift가 이동이고, macOS는 ⌥이 복사, ⌘이 이동입니다.
  - 보조키가 없으면 보기 ▸ 설정의 기본 동작을 따릅니다: 이동(기본값), 복사, OS 방식, 매번 묻기.
  - 커서 옆에 "이동 → 폴더"처럼 무엇을 할지 보입니다.
- **머무르면 열기와 자동 스크롤:** 폴더·탭·트리 위에 1초 머물면 그곳이 열립니다. 목록 끝에 머물면 굴러갑니다.
- **옮긴 뒤 되돌리기 알림:** 끌어서 옮기면 5초 동안 "항목 N개를 옮겼습니다 [되돌리기]"가 뜹니다.
- **Windows 메뉴:** Shift+오른쪽 클릭, Shift+F10, 앱 메뉴의 "더 많은 옵션 표시"로 탐색기의 오른쪽 클릭 메뉴를 띄웁니다. "보내기", "연결 프로그램", 셸 확장 항목이 있습니다.
- **macOS 공유:** 항목 메뉴의 "공유…"로 AirDrop, 메일, 메시지 등을 띄웁니다.
- 1판과 2판의 기능(두 패널과 탭, 복사·이동·휴지통·되돌리기, 보기와 열, 빠른 보기, 클립보드, 속성·체크섬, 트레이 등)은 그대로입니다.

## 먼저 확인해 주세요: 원본이 남는지

- **Windows:** 탐색기에서 Shift를 누른 채 앱으로 끌어 이동하면, 앱의 복사가 끝나기 전에는 탐색기 쪽 원본이 남아 있어야 합니다.
- **macOS:** Finder에서 끌어 이동할 때 Finder가 원본을 지우거나 그림을 되돌리지 않아야 합니다.
- **둘 다:** 앱에서 끌어낸 뒤 앱이 아무것도 지우지 않아야 합니다.
- **macOS:** 창 위로 끌어 온 파일에 놓을 곳이 강조되는지 봅니다. 투명한 받기 뷰의 확인입니다.

나머지 확인 목록은 [README의 "실제 PC에서 손으로 확인할 것"](https://github.com/doguri25/Racoon-Finder/blob/v0.3.0/README.md#실제-pc에서-손으로-확인할-것)에 있습니다.

## 알아 둘 점

- **끌어 놓기의 기본 동작은 이동입니다.** 다른 드라이브에서 끌어 온 것도 옮깁니다. 탐색기처럼 하려면 "끌어 놓기: OS 방식"을 고릅니다.
- **Windows에서 다시 그려지지 않는 때:** 끌어내는 동안과 Windows 메뉴가 떠 있는 동안에는 앱 창이 다시 그려지지 않습니다.
- **Windows 메뉴:**
  - Shift+삭제는 확인 창을 거친 뒤 영구 삭제라 되돌릴 수 없습니다.
  - 셸 확장은 앱 안에서 돌기 때문에, 잘못 만든 확장이 앱을 멈출 수 있습니다.
- **아직 없는 것:** 링크 만들기, 압축해서 넣기, 앱 안의 오른쪽 버튼 끌기, Linux에서 끌어내기와 Wayland, 썸네일, 설치 프로그램.

자세한 내용은 [README](https://github.com/doguri25/Racoon-Finder/blob/v0.3.0/README.md)와 [키 설명서](https://github.com/doguri25/Racoon-Finder/blob/v0.3.0/docs/ux/keyboard.md)에 있습니다.
